# Sample reports

These files are **generated by the real domain code**, not hand-written. They
demonstrate the `sentinelnet.report/1` schema and double as golden fixtures.

Regenerate them with:

```bash
./gradlew :core:pure:conformance --args="--emit-samples=../../docs/samples"
# or, without Gradle:
./scripts/verify_domain.sh --emit-samples=docs/samples
```

| File | Contents |
|---|---|
| `wifi_scan_report.json` / `.csv` | Four observed networks (WPA3, WPA2+WPS, open, WEP) |
| `security_audit_report.json` | Wrapped document with score, categories, findings, remediation plan and a SHA-256 chain-of-custody hash |
| `security_findings.csv` | Prioritised findings |
| `port_scan_report.csv` | Example port results |
| `device_discovery.csv` | Enriched devices with vendor/type guesses |
| `capture_summary.json` | Flow-level capture summary (metadata only) |
| `audit_log.json` | Allowed, denied and observed consent decisions |
| `security_lab_walkthrough.json` | Synthetic WPA lab result with PMK/MIC values |

`scripts/verify_project.py` parses every JSON file with Python's `json` module
and every CSV with `csv.reader`, and asserts the security report has a valid
chain-of-custody hash.

**Note:** the data is fictional and uses a fixed timestamp
(2023-11-14T22:13:20Z) so the samples are reproducible.
